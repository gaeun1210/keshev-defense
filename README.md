# 케셰브 (KESHEV) — 실행 안내 한 장

케셰브는 내 PC의 상태(CPU·메모리·디스크·방화벽·네트워크·Windows 기록 건수)를 **일반 권한으로 읽기만 해서** 보여 주는 보안 관제 대시보드입니다.
설정을 바꾸지 않고, 관리자 권한을 쓰지 않고, 값을 밖으로 보내지 않습니다. 처음 실행은 예제 모드(`-Demo`)로 하며, 이때 로그인·기기·세션 칸은 예제 자료이고 **SDP 서버에는 연결하지 않습니다**.

> 시연 순서·한계·근거는 [`ALEPH_FINAL_WORK_RECORD.md`](ALEPH_FINAL_WORK_RECORD.md), 화면 캡처는 [`docs/showcase/`](docs/showcase/)에 있습니다.
>
> 이 안내는 처음 보는 사람이 혼자 따라 하도록 썼습니다. 막힌 곳이 있으면 맨 아래 「막혔을 때」를 보고, 그래도 안 되면 막힌 단계 번호와 화면의 문구를 그대로 알려 주세요.

## 1. 준비물 (처음 한 번)

| 준비물 | 확인 방법 |
|---|---|
| Windows 10/11 PC | — |
| **Node.js 22~24판** (수업 기준 24.19.0) | PowerShell에서 `node --version` → `v22.…`~`v24.…`이면 됩니다. 없거나 `v25` 이상이면 <https://nodejs.org> 에서 **24판(LTS)** 을 설치한 뒤 **PowerShell 창을 새로 엽니다** |

`npm install` 같은 추가 설치는 **필요 없습니다**(외부 패키지를 쓰지 않습니다). Git도 없어도 됩니다.

## 2. 받기

- **Git 없이:** <https://github.com/gaeun1210/keshev-defense> → 초록색 **Code** → **Download ZIP** → 받은 ZIP을 오른쪽 클릭 → **모두 압축 풀기**. 기존에 쓰던 폴더가 아니라 **새 폴더**에 풉니다.
- **Git으로:** `git clone https://github.com/gaeun1210/keshev-defense.git`

## 3. 실행

1. 받은 폴더 안의 **`on-client`** 폴더를 엽니다(`package.json`·`tools`·`student` 폴더가 보이는 곳).
2. 탐색기 **주소창**을 클릭하고 `powershell` 입력 → Enter. 그 폴더에서 PowerShell이 열립니다.
3. 아래 한 줄을 붙여 넣고 Enter:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo
   ```
   `-ExecutionPolicy Bypass`는 이 한 번의 실행에만 적용되며 컴퓨터 설정을 바꾸지 않습니다.
4. 「**케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189 을 여세요.**」가 나오면 브라우저에서 그 주소를 엽니다. **이 PowerShell 창은 닫지 마세요**(닫으면 앱이 꺼집니다).

## 4. 첫 화면 확인 (약 1분)

1. 왼쪽 메뉴 **보호 현황** → 로그인 칸 바로 아래 **「내 PC 관제 대시보드」** 가 보입니다.
2. **「다시 조회」** 를 누릅니다(Tab으로 이동해 Enter를 눌러도 됩니다). 자동으로 다시 읽지 않으므로 누를 때만 읽습니다.
3. 아래가 보이면 성공입니다.
   - **한눈 요약** 한 줄 · **① 상태 카드** 4개(값마다 「실측」과 잰 시각)
   - **연결과 기록**의 SDP 줄이 「**SDP 미연결** · 예제 모드로 실행 중」 — 예제 모드에서는 이것이 정상입니다
4. 「다시 조회」를 2번 더 누르면 **② 추이** 그래프 3개와 **③ 최근 기록** 이 쌓입니다. [전체] [주의] [확인 불가] 버튼으로 기록을 나눠 볼 수 있습니다.
5. 대시보드 오른쪽 위 **[밝게 | 어둡게]** 로 대시보드 화면 밝기를 바꿀 수 있습니다(값과 기능은 같습니다).

> **값은 사람마다 다릅니다.** 화면의 숫자는 그 PC에서 잰 실측값이라 이 안내와 같은 숫자가 나오지 않는 것이 정상입니다. 예를 들어 아래는 **예시 값(설명용, 실제 조회 결과 아님)** 입니다.
> `예시 · 한눈 요약: 주의 1 (디스크 남은 공간) · 확인 불가 0 · 실측 5 · SDP 미연결`
> 「주의」는 기준을 넘은 실측값(예: 디스크 여유 10 % 미만)이고, 「확인 불가」는 읽지 못한 항목(이유가 함께 나옴)입니다. Windows 기록 경고·오류 건수는 **침해나 공격 탐지 결과가 아닙니다.**
> 앱의 「확인 불가」는 **그 항목의 값을 이번 조회에서 읽지 못했다는 표시**입니다. 방어전 판정 카드의 「확인 불가」와는 다른 뜻이며, 정상이나 0으로 바꾸어 보여 주지 않습니다.

## 5. 끄기

PowerShell 창에서 **Ctrl+C**. 그래도 꺼지지 않으면 **Ctrl+Shift+Esc**(작업 관리자) → **Node.js JavaScript Runtime** → **작업 끝내기**.

## 막혔을 때

| 보이는 문구 / 상황 | 원인 | 할 일 |
|---|---|---|
| `Node.js 가 없습니다` / `node`를 찾을 수 없음 | Node.js 미설치 | 1번 준비물대로 24판 설치 → **새 PowerShell 창**에서 다시 실행 |
| `지금 Node.js 는 v25… 입니다. 앱은 Node.js 22~24 에서 실행합니다` | 지원하지 않는 판 | Node.js 24판(LTS) 설치 |
| `앱 폴더가 아닙니다` | `on-client`가 아닌 폴더에서 실행 | 「3. 실행」의 1단계대로 `package.json`이 보이는 `on-client` 폴더에서 실행 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 이미 앱이 켜져 있거나 다른 프로그램이 사용 중 | 켜 둔 앱이 있으면 5번대로 끄거나, 명령 끝에 ` -Port 5190`을 붙이고 http://127.0.0.1:5190 을 엽니다 |
| 브라우저에 「사이트에 연결할 수 없음」 | 앱이 꺼졌거나 주소가 다름 | PowerShell 창이 열려 있는지 확인 → 「3. 실행」의 4단계에서 PowerShell에 나온 주소를 그대로 엽니다 |
| 대시보드에 빨간 상자 **「이번 조회 실패 (NETWORK_ERROR)」** | 조회 중 앱이 꺼짐 | 상자의 「다음에 할 일」대로: ① 앱 실행 창 확인 ② 꺼졌으면 3번 명령으로 다시 켜기 ③ 「다시 조회」 |
| **「이번 조회 실패 (TIMEOUT)」** | PC가 바빠 시간 초과 | 10초쯤 기다린 뒤 「다시 조회」. 계속되면 앱을 껐다 켜기 |
| 카드에 **「확인 불가」** 와 이유 | 그 항목을 읽지 못함(권한 없음 등) | **관리자 권한으로 바꾸지 마세요.** 이유 문구를 그대로 알려 주세요 |
| 화면 위에 꾸밈 파일 문제 안내 | `student/appearance.json` 내용 오류 | 기본 화면으로 계속 쓸 수 있습니다. 안내 문구를 그대로 알려 주세요 |
